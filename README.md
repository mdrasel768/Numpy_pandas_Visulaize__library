# Data Science Basics: NumPy, Pandas & Data Visualization

Welcome to this repository! This project showcases practical data manipulation, processing, and visual exploration techniques using core Python data science libraries.

## Topics Covered
- NumPy: Multi-dimensional arrays, mathematical computations, and slicing
- Pandas: DataFrames, Series, data cleaning, filtering, and aggregation
- Data Visualization: Matplotlib & Seaborn plots, customization, and heatmaps

## Tools & Environment
- Language: Python 3.x
- Environment: JupyterLab / Jupyter Notebook
- Version Control: Git & GitHub
